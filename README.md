# Laboratorio del Cubo

Pagina didattica: matematica e informatica con un cubo di Rubik (riduzione,
algoritmi e periodi, invarianti, commutatori, numero di Dio, simulazione).
Tutti i cubi sono animati da un simulatore JavaScript nella pagina stessa.

- Sito: https://cubo.privix.org (GitHub Pages, workflow `.github/workflows/pages.yml`)
- `index.html`: pagina autonoma, nessuna dipendenza oltre ai Google Fonts
- `cubo.py`: lo stesso simulatore in Python, mostrato nella sezione 6

```bash
python cubo.py
```
